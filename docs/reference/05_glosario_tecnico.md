# Glosario técnico

## ASGI

Interfaz usada por FastAPI y Uvicorn.

## APIRouter

Componente que agrupa rutas de un módulo.

## Data Lake

Repositorio de datos originales organizados por particiones.

## Parquet

Formato columnar comprimido.

## Hive partitioning

Convención `year=YYYY/month=MM/day=DD` reconocida por motores analíticos.

## Arrow

Modelo columnar interoperable utilizado por PyArrow y otras librerías.

## join_asof

Unión temporal que busca el último valor disponible anterior o igual a una observación.

## rolling window

Cálculo sobre una ventana móvil de observaciones anteriores.

## Data leakage

Uso accidental de información futura o del target dentro de las entradas.

## OOM

Fallo por memoria insuficiente.
